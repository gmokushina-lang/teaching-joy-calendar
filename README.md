# Teaching & Joy — календарь преподавателя

Русскоязычный веб-сервис для записи учеников на индивидуальные занятия и управления расписанием преподавателя. Интерфейс выполнен в авторском стиле Neo Kingdom — как волшебная книга путешествий.

## Возможности

- календарь занятий на месяц и недельный вид на телефоне;
- отдельные роли преподавателя и ученика;
- вход по электронной почте и паролю через Firebase Authentication;
- создание учеников, абонементов и повторяющихся еженедельных занятий;
- занятия продолжительностью 45, 50 или 60 минут;
- перенос и отмена отдельного урока или удаление всей серии;
- отметка проведённого урока;
- материалы занятия, комментарий преподавателя и домашнее задание;
- подсчёт оставшихся занятий в абонементе;
- карта путешествия, которая отражает прогресс ученика;
- хранение данных в Cloud Firestore с разграничением доступа.

[Открыть опубликованный сайт](https://teaching-joy-calendar.web.app/)

## Технологии

React, TypeScript, Vite, Firebase Authentication, Cloud Firestore и Firebase Hosting.

## Локальный запуск

1. Установить зависимости: `pnpm install`.
2. Скопировать `.env.example` в `.env.local` и заполнить параметрами своего проекта Firebase.
3. Запустить сайт: `pnpm dev`.

Файл `.env.local` не публикуется в репозитории.
